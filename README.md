## 🇷🇺 Русская тема для WiFi Pineapple Pager

**Полностью русифицированная тема `wargames` для WiFi Pineapple Pager от Hak5.**

### 📋 Что переведено
- **Главное меню:** Полностью на русском (Dashboard, Recon, PineAP, Settings, Payloads).
- **Разделы:** Все подменю и списки.
- **Диалоги:** Окна подтверждений, ошибок, ввода данных и оповещений.
- **Настройки:** Яркость, громкость, рингтоны, сетевые параметры и система.
- **Обучение:** Все шаги мастера первоначальной настройки (`Setup Wizard`) и экраны обучения (`Tutorial`).
- **Конфиги:** Файлы настройки Bluetooth.
- **Скрипты:** Отчеты и логи `payload`-скриптов.

### ⚙️ Установка
Следуйте этой инструкции, чтобы безопасно установить тему, не нарушив работу устройства.

1.  **Загрузите тему на Пейджер** (с вашего ПК):
    ```bash
    
    scp -r ./wargames root@172.16.52.1:/root/themes/russian_theme/

2. Возьмите пейджер и в настройках найдите в первом раздели Theme:
   Поменяёте на ---> russian_theme

3. Поздровляю!!!
